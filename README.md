# Veger: A Simple Python Space Invaders Clone

This project is a lighthearted Python game where you play as **Bartleby the Turtle**, standing in the road and shooting at falling alien invaders. The game speeds up over time, challenging your reflexes.

- **Built with:** Python + Tkinter (turtle module)
- **Purpose:** Fun project to explore basic game mechanics, event loops, keyboard controls, and animation in Python.
- **Title origin:** The name *Veger* is an accidental abreviation of Voyager from *Star Trek: The Motion Picture*.

### Features
- Simple player controls (move, shoot).
- Accelerating alien enemies.
- Score tracking.

### Why This Exists
This was a personal side project to experiment with Python’s `turtle` module and basic game design principles. It’s not a commercial or polished game but a just some playful Python experimentation.
